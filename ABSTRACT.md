# Abstract
## Railway Platform Management System Using Data Structures

The Railway Platform Management System is a Java-based mini project that demonstrates how data structures can help organize train arrivals and platform allocation. The project focuses on a Queue and a Priority Queue.

A normal queue manages trains waiting for platform allocation according to their arrival order, following the First-In-First-Out (FIFO) principle. A priority queue is used when some trains, such as emergency or special-service trains, must be handled before other waiting trains. The system supports adding trains, viewing waiting trains, allocating a platform, processing the next train, and assigning priority.

The project illustrates practical applications of data structures and helps demonstrate organized, efficient handling of multiple trains. It is an educational prototype and does not connect to a real railway signalling or scheduling system.
